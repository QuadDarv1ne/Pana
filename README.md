Pana — это хаб 3D-вечеринок, которые запускаются прямо в браузере. Ты создаёшь своего пана (капибару в твоей шляпе, очках и наряде) один раз в хабе, и он играет с тобой в каждую игру: он водит твою машину, скачет на твоей лошади, готовит твои арепы и сидит за столом с домино. Открой игру, отправь ссылку друзьям — и вы уже в одной комнате.

## Играть

Публичный сайт скоро откроется на **pana.sh**. До тех пор запускай его на своём компьютере и делись им по сети:

```powershell
git clone https://github.com/jhd3197/Pana
cd Pana
npm install
npm start                 # или .\dev.ps1 на Windows
```

Открой http://localhost:8461. Скрипт разработки также печатает адрес в локальной сети: друзья в той же Wi-Fi сети открывают его, выбирают игру и жмут *Invitar panas*, чтобы поделиться комнатой.

- **Pana Studio** (`.\dev.ps1 studio`): каждый общий персонаж, реквизит, транспорт и карта с живым 3D-предпросмотром и исходным файлом.
- **Редактор персонажа**: `/personaje.html` — визуальный гардероб, предпросмотр аксессуаров, undo/redo и коды нарядов; сохрани полный образ для каждой игры.

## Релизы

Каждый мердж из `dev` в `main` — это релиз. Workflow проставляет заметки `## Unreleased` в [CHANGELOG.md](CHANGELOG.md) следующей версией, тегает её и публикует их как [GitHub-релиз](https://github.com/jhd3197/Pana/releases). Что изменилось и когда — всегда в changelog.

## Разработка

Один Node-сервер, статический хаб и одна папка на игру: обычные ES-модули **без шага сборки**, Three.js с CDN и комнаты Colyseus для онлайн-игры.

```powershell
npm run check             # синтаксическая проверка каждого .js-файла
npm test                  # юнит-тесты + проверки домашних правил (браузер не нужен)
npm run test:browser      # Playwright-сьюты (ставятся через npm install)
.\dev.ps1 check -Browser  # всё вышеперечисленное
```

```
README.md, AGENTS.md, CHANGELOG.md, dev.ps1, package.json
docs/                  архитектура, деплой, knowledge/ (заметки по разделам), screenshots/
Pana/
├── server/            HTTP, API и комнаты Colyseus
├── web/               хаб, создатель персонажа и Pana Studio
├── games/<game>/      game.json + public/ (rules.js, network.js, scene.js, game.js) + tests/
├── engine/            общий код: kit, menu, rooms, invites, results, icons, models
├── scripts/           раннер тестов и инструменты релиза
└── tests/             проверки домашних правил
```

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): поток запросов, файлы игры, комнаты.
- [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md): запуск своего сервера.
- [docs/knowledge/](docs/knowledge/README.md): заметки по каждой игре и разделу.

## Контрибьютинг

Работа идёт на `dev`; `main` принимает только мерджи из него. Этот репозиторий в значительной степени построен ИИ-агентами для кодинга, так что начни с [AGENTS.md](AGENTS.md); он короткий. Изменение, которое заметят игроки, добавляет строку под `## Unreleased` в [CHANGELOG.md](CHANGELOG.md) в том же коммите: эта строка станет релизными заметками.
